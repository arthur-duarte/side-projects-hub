# Side Projects Hub

Repositório para projetos independentes.

- [Roku Livre +](./roku-livre/) — controle remoto Android para dispositivos Roku na rede local, sem anúncios.

- [FiguFábrica Mobile](./figufabrica-mobile/) — fonte Flutter para compilar versões nativas Android e iOS.
